# Documentación

Última actualización: 2026-11-11.

El punto de entrada es el [índice de documentación](index.md). Para el uso cotidiano abre el [manual de Kairos](manual.md); para integrar un agente empieza por [instalación](install.md) y continúa con el [contrato MCP](integration.md).

El estado implementado y sus fuentes están en [arquitectura](architecture.md). Desde el 2026-11-11 describen también la calidad de recuperación (pgvector, búsqueda léxica por idioma, fragmentos, degradación, logs y métricas); esas mejoras están implementadas y probadas en entornos aislados, pero **no están desplegadas** en la instalación local hasta que se autorice su despliegue ([operación](operations.md)). La publicación de un paquete y la aceptación de clientes reales se indican como pendientes cuando no hay evidencia de ejecución.
